# dasi-bom (다시 봄)

> 완경기 여성의 흩어진 몸·마음·피부 신호를 AI가 하나로 연결해, 매일의 생활습관으로 풀어주는 서비스

순천향 멋쟁이사자처럼 해커톤 1팀 "얼룩덜룩"

## 문제 정의

완경에 접어든 50대 여성 A씨. 직장에 다니면서 동시에 자녀의 등하교와 부모님 병원 동행까지 챙기느라, 자기 몸에 이상 신호가 와도 '나중에'로 미루는 사람.

- **인지 못함**: 홍조 등 증상이 하루 서너 번 반복돼도 "사건"으로만 느껴지고 "데이터"로 축적되지 않음
- **고립**: 가족에게 증상을 말해도 공감받지 못해, 말할 언어도 들어줄 사람도 부재
- **판단 기준 부재**: "이게 병원 갈 정도로 심각한가"를 스스로 판단할 근거가 없어, 비용을 따지기도 전에 예약을 포기
- **디지털 낯섦**: 앱 온보딩 단계에서 "이게 나를 위한 것인가"라는 자기 검열로 3분 내 이탈

## 솔루션

> 예측할 수 없는 갱년기 증상 앞에서 막막한 50대 여성을 위해, 몸·마음·피부 데이터를 하나로 엮어 '오늘 컨디션이 왜 이런지' 설명해주고, 바쁜 하루 틈새에 자기 돌봄을 심어주는 도구

### 핵심 기능

1. **저녁 증상 기록 + AI 분석 리포트**
   - 낮 동안 원터치로 증상 즉시 기록
   - 저녁 종합 체크인(버튼/슬라이더 중심, 입력 부담 최소화)으로 수면·감정 등 보완 기록
   - 주간 패턴 리포트 제공 (예: "이번 주 홍조 4회, 주로 저녁 시간대")
   - 며칠간 기록 안 된 과거 증상을 AI가 먼저 물어봄
2. **생활 정보 길잡이 챗봇**
   - 초기: 정서적 위안 중심의 음성 대화(TTS)로 낮은 진입 장벽
   - 관계가 쌓이면 병원 과·영양제 등 실용 정보로 확장
3. **알림 (복약·영양제 + 명상·스트레칭)**
   - 복약/영양제 시간 알림
   - 3~5분 명상·스트레칭 알림으로 병원 없이도 가능한 첫 관리 단계 제공

### 성공 지표

사용자 중 60% 이상이 2주 연속 주 5일 이상 기록을 완료하면 성공

### 데이터 · 제약

기본적으로 목업 데이터를 구축해서 사용하되, Google Health 연동과 얼굴 사진 분석 기능은 실제로 구현한다. 단, MVP 시연에서는 목업 데이터(사전 준비된 얼굴 사진·생활 정보)로 심사위원이 직접 연동하지 않아도 되게 한다.

## 브랜치 전략

- **기본 브랜치는 `develop`** — 팀원들은 `develop`에서 기능 브랜치를 따서 작업 후 `develop`에 PR/머지
- `main`은 배포·심사용 안정 브랜치. `develop` → `main`은 PR을 통해서만 반영되며, 리뷰 승인 1건이 있어야 머지 가능 (직접 push·강제 push·삭제 불가)

### 브랜치 네이밍 규칙

**이름·역할이 아니라 구현하는 기능/작업 기준**으로 짓습니다. `develop`에서 분기.

```
<타입>/<기능-설명>
```

- `feature/<기능-설명>` — 새 기능 (예: `feature/symptom-log`, `feature/chatbot-voice`, `feature/face-analysis`, `feature/med-reminder`)
- `fix/<버그-설명>` — 버그 수정 (예: `fix/login-crash`)
- `chore/<작업-설명>` — 설정·문서·리팩터링 등 (예: `chore/ci-setup`)

규칙: 소문자, 단어 사이는 `-`, 영문 키워드 권장(도구 호환). 담당자 이름은 브랜치명에 넣지 않고 PR 작성자로 자연히 드러나게 함.

```bash
git clone https://github.com/jsi4770/dasi-bom.git
cd dasi-bom
git checkout develop
git checkout -b feature/symptom-log   # develop에서 기능 브랜치 생성

# 작업 후
git push -u origin feature/symptom-log
gh pr create --base develop --head feature/symptom-log
```

`develop`이 어느 정도 쌓이면 리뷰 후 PR로 `main`에 반영:

```bash
gh pr create --base main --head develop --title "릴리즈: ..."
```
